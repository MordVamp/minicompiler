# Спринт 7: Массивы и Внешние функции

В рамках этого спринта язык MiniCompiler был расширен поддержкой сложных структур данных (массивов) и возможностью взаимодействия со стандартной библиотекой C.

## 1. Поддержка массивов

### Синтаксис
Массивы объявляются с указанием размера в квадратных скобках. Поддерживается опциональная инициализация списком значений.

```c
int arr[5];             // Неинициализированный массив
int fib[3] = {1, 1, 2}; // Массив с инициализацией
```

### Доступ к элементам
Доступ осуществляется через оператор `[]`. Индексация начинается с 0.

```c
arr[0] = 10;
int x = arr[1];
```

### Реализация
*   **Память:** Массивы выделяются на стеке целиком. Для `int arr[5]` резервируется 40 байт (5 элементов по 8 байт).
*   **Адресация:** Используется инструкция `lea` для вычисления базового адреса и `shl/add` для вычисления смещения индекса.

## 2. Взаимодействие с библиотекой C (ABI)

Компилятор теперь автоматически поддерживает вызовы стандартных функций.

### Доступные функции
*   `printf(string fmt, ...)` — вывод в консоль.
*   `scanf(string fmt, ...)` — ввод из консоли.
*   `malloc(int size)` — динамическое выделение памяти.
*   `free(int ptr)` — освобождение памяти.

### Особенности реализации
*   **System V ABI:** Перед вызовом вариативных функций (`printf`, `scanf`) регистр `eax` обнуляется.
*   **Строковые литералы:** Все строки в коде автоматически извлекаются и помещаются в секцию `.data` с уникальными метками.
*   **Стек:** Соблюдается выравнивание стека по 16 байт для корректной работы внешних функций.

## Пример кода (`examples/test_extern.src`)
```c
fn main() -> void {
    printf("Testing external functions:\n");
    int ptr = malloc(40);
    printf("Allocated 40 bytes at address: %d\n", ptr);
    free(ptr);
    printf("Done!\n");
}
```
